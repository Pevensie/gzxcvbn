# gzxcvbn Demo

Interactive demo for [gzxcvbn](https://github.com/Pevensie/gzxcvbn), the password strength estimation library for Gleam.

**[Try it live](https://gzxcvbn.pevensie.dev)**

## Features

- Real-time password strength analysis
- Visual strength meter
- Crack time estimates for multiple attack scenarios
- Feedback and suggestions for improvement
- Pattern analysis showing detected matches

## Development

```sh
gleam run -m lustre/dev start  # Start dev server
gleam run -m lustre/dev build  # Build for production
```

## Built With

- [Gleam](https://gleam.run) - Language
- [Lustre](https://hexdocs.pm/lustre) - Frontend framework
- [Tailwind CSS](https://tailwindcss.com) - Styling
